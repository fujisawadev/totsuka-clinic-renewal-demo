旧トップページの各セクション → 新サイトでの行き先

旧サイトのトップページには「院長挨拶」「資格・経歴」「お知らせ」など複数の情報が 1 ページに集約されていました。新サイトでは、それぞれを適切な独立ページとして分散配置しています。

  • NEWS
    臨時休診案内・GW休診案内など。
    → /news/
  • 院長挨拶（ご挨拶）
    院長メッセージ本文。
    → トップ Greeting セクション（要約）
    + /doctor/（フル版）
  • 資格・経歴
    歯科医師・歯学博士・認定医、大学病院での経歴。
    → /doctor/
  • 所属学会・所属機関・主な役職
    日本矯正歯科学会、東京矯正歯科学会、戸塚区歯科医師会等。
    → /doctor/
  • 地域医療
    園歯科医・地域保健委員の活動。
    → /doctor/
  • 年別症例件数
    10 年毎・30 年間の推移データ（合計 5,694 件）。
    → /achievements/
  • 横浜ドクターズインタビュー
    外部メディアでのインタビュー紹介。
    → /interview/
  • 採用情報
    スタッフ採用情報。
    → /recruit/
  • デンタルローン案内

    → /pricing/（料金ページの注記に統合）

  • カウンセリング風景
  • 各装置の写真
  • スタッフ写真（採用ページ用）

いずれも仮のグレーボックスで表示中。実写真をご提供いただき次第、差し替えます。

テキスト（特定の枠）

  • ヒーローのキャッチコピー
  • コンセプトのリード文
  • 小児矯正の専用ページ用本文
  • 成人矯正の専用ページ用本文
  • マウスピース型矯正の説明文
  • SNS（Instagram / Tiktok）のアカウントURL
  • Google Map の埋め込み
  • 採用情報の具体的な募集要項
  • 横浜ドクターズインタビューの外部リンクURL
  • 横浜セクションの 12 トピック本文
  • 横浜 Q&A 94 件の本文精読・最新化

新サイトのデザインに沿って必要な枠を確保しています。原稿の内容は別途ご相談しながら決められます。

補足：トップページに配置した「枠」だが旧サイトに該当コンテンツがないもの
  • コンセプト（Concept）セクション ── 新サイトのデザイン上、医院の方針を伝える重要な枠。旧サイト院長挨拶から 3 つの特徴を抽出して暫定的に表示中
  • 年齢別（小児／成人）カード ── 装置・治療法による分類とは別の入口として用意。旧サイトに専用ページがないため、新ページを作るか別の入口に置き換えるかご相談
  • 装置・方法から探す（マウスピース／ワイヤー）カード ── 旧サイトの「矯正装置」ページに集約。デバイス別の独立ページを作るかご相談

Next Steps

ご確認・ご判断いただきたい事項

  1. 小児矯正・成人矯正・マウスピース型矯正の専用ページは作りますか？
    旧サイトには専用ページがなく、新サイトの「年齢別」「装置・方法」入口は現状リンク先がありません。
  2. SNS（Instagram / Tiktok）のアカウントURLをご提供ください。
    フッターおよび Access ページで使用します。
  3. ヒーロー画像 / 院内写真 / 症例写真の素材をご提供ください。
    旧サイトの写真を再利用するか、新規撮影するかをご判断ください。

    新サイトには旧サイト本文を要約して掲載しています。リニューアルを機にリライトされる場合は原稿をお願いします。
