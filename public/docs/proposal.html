Project Goals

このプロジェクトで実現したいこと

単なる「見た目を新しくする」リニューアルではありません。患者さんとの最初の接点としての Web サイトを、いまの来院プロセスに合った道具に再設計します。

01 / Brand

選ばれる医院イメージの確立

矯正専門医院としての専門性と、患者さん本位の診療姿勢を、現代的で清潔感のあるトーンで伝える。第一印象を「信頼できる医院」に。

02 / Mobile

スマホ中心の利用環境への最適化

患者さんの 7 割以上はスマートフォンで医院を探します。レスポンシブ設計と短い予約導線で、訪問→相談予約までの離脱を最小化。

03 / SEO

SEO 資産を継承し集患を維持

現行サイトの 113 ページ（うち 94 本の Q&A 記事）が築いてきた検索流入を、URL 構造の刷新とリダイレクトで丁寧に引継ぎ、リニューアル後も継続的な集患を確保。

Why now

現行サイトは長年運用されてきた一方、文字コードが Shift-JIS、レスポンシブ未対応、HTML 構造が古く、現在の Google 検索評価基準やユーザー体験の標準から離れつつあります。SEO 資産を保ったままで早めに刷新することで、競合医院との差別化を維持できます。

Design Highlights

デザインリニューアルの主要ポイント

参考にした品川矯正歯科の上品な設計言語をベースに、ささき矯正歯科の文脈に合わせて再構成しました。デモサイトをスクロールしながら、以下のポイントをご確認ください。

Hero ── 第一印象

「戸塚駅東口より徒歩 3 分」「日本矯正歯科学会 認定医」を冒頭で訴求。医院名を 4xl サイズで大胆に配置し、患者さんへのキャッチコピーを下部に配置。

Greeting ── 院長挨拶

院長写真を中央大判で配置し、35 年以上の臨床経験と認定医としての安心感を視覚的に伝達。デスクトップは縦書き、モバイルは横書きで可読性を最適化。

01／02／03 のナンバリングで医院の特徴を 3 つに整理。フルブリードの写真背景＋ダークオーバーレイで重厚感を演出。

現行サイトの構成を踏襲し、「不正咬合の種類から探す」切り口でカード型に整理。患者さんが症状名から直接入口を見つけられる導線設計。

※ 参考の品川矯正歯科サイトには「年齢別で探す」「装置・方法から探す」の追加軸があります。今回はベース実装をシンプルに保ち、必要に応じてご要望ベースで追加可能としています（確認事項参照）。

Counseling ── 初診相談

「初診相談は無料」のメッセージを大きく訴求。STEP1〜STEP4 の流れを可視化することで、初めての患者さんの不安を軽減。

Access ── 医院情報

診療時間（平日／土日）、休診日、駐車場（TY 上倉田駐車場との提携情報）、Google Map 連携を 1 ページで完結。

Information Architecture

情報設計の刷新

現行サイトでは「よくある質問」と「横浜の矯正歯科 Q&A（94 本の SEO 記事）」が似た形式で混在しており、ユーザーにとって役割が判別しにくい状態です。新サイトではそれぞれの役割を明確に分離します。

Issue ── 現状の問題

・現行 /question.html（よくある質問 9 件）
・現行 /yokohama-orthodontic-dentistry/（94 件の SEO 記事 ハブ）

両者とも「質問と回答」形式で見た目が似ており、患者さんがどちらを見ればいいか判断しにくい。SEO の観点でも内部リンク評価が分散している。

Proposal ── 新サイトでの整理

・/faq/ → 患者さん向け FAQ（来院前のよくある疑問）
・/columns/ → 矯正歯科コラム（旧 /yokohama-orthodontic-dentistry/ をリネーム＋カテゴリ整理）

役割を明確化することで、ユーザー体験と SEO の両方を改善します。

SEO 記事 94 本の取り扱い方針

積み上げてきた 94 本の SEO 資産は1 本も削除せず、URL も 1:1 で引き継いで全保持します。記事構造の変更や統合はしません（被リンク・検索評価の継承を最優先）。

項目 新サイトでの扱い
記事本数 94 本すべて維持（削除・統合なし）
URL 引継ぎ 旧 URL → 新 URL を 1:1 マッピング、全件 301 リダイレクト
掲載場所 /columns/（旧 /yokohama-orthodontic-dentistry/）配下に「矯正歯科コラム」として体系化
管理方法 新サイト構造に静的ページとして一括移管。URL とコンテンツを 1:1 で引継ぎ
今後の運用 新規記事の追加・既存記事のブラッシュアップは弊社対応（ご依頼ベース）

※ 旧 URL からの 301 リダイレクトを全件実装し、検索評価・被リンク資産を完全に新 URL へ継承します。

Content Operation

ニュース運用の引継ぎ

現行サイトのニュース（休診案内・お知らせ等）は、news.cgi という現サイト構築ベンダーが独自に作成した専用プログラムで動的に表示されています。これは汎用 CMS ではなく、新着情報の表示に特化した軽量な仕組みです。新サイトでは、先生の現状の更新フローをそのまま引き継ぐ方針です。リニューアル後も、これまでと同じ感覚でニュースを更新していただけます。

調査結果 ── 現行の運用

仕組み: ベンダー独自実装の専用 CGI（news.cgi）
記事数: SEO 記事 94 本＋お知らせ多数
更新頻度: 月 1 本ペースで継続追加
更新方法: 現サイト構築ベンダーが提供する管理画面で投稿 / もしくはベンダーへの更新依頼ベース（要ヒアリング）

新サイト ── 現運用の継承

方針: 先生の現状フローを尊重し、同等運用を継承
流れ: ご連絡 → 弊社でテキスト編集 → 自動デプロイで即日公開
既存記事: 94 本＋お知らせを新サイト構造に静的ページとして一括移管
先生の作業: 変わりません。これまで通り「○月○日休診」と一言お伝えいただくだけ

引継ぎ確認項目 ── ベンダーヒアリング

新サイトでも同等の運用を提供するため、現サイト構築ベンダーに以下を確認させていただきます。

確認項目 目的
現状のニュース更新フロー 管理画面からの投稿 / ベンダーへの依頼 / その他、のいずれの方式か
管理 UI の有無・引継ぎ可否 管理画面がある場合、ID/PW 等の譲渡可否や仕様の共有可否
これまでの更新頻度・対応リードタイム 新サイト運用での対応速度の目安として参考
ちなみに ── ご自身で投稿される構成にも対応可能

もし現在の運用に手間や不便を感じておられる場合は、Headless CMS（Sanity・microCMS 等）を別途導入し、先生やスタッフさまがブラウザから直接投稿できる構成にも対応可能です。基本提案は現運用の継承とし、ご希望があれば追加要件としてご相談ください（別途お見積り）。

08 / 11
SEO Migration Plan

SEO 資産の引継ぎ戦略

リニューアル時に最も気になるのが「これまでの検索順位は維持できるのか」というご不安です。新サイトでは以下のステップを順序立てて実施し、SEO 評価を毀損せず継承します。

1

URL マッピング作成

現行 19 ページ＋ 94 SEO 記事＝113 URL すべてに新 URL を 1:1 で割当てます。ヌケモレが無いよう、リストを 付録（migration-overview.html） として既にドラフト済み。

2

301 リダイレクトの実装

旧 URL にアクセスした場合、新 URL に恒久的にリダイレクト。検索順位・被リンク・ブックマークがすべて新 URL に継承されます。サーバー側 (.htaccess または Nginx) または CDN レイヤー (Cloudflare 等) で実装。

3

新サイト側 SEO 施策

・各ページに <link rel="canonical"> を設定
・sitemap.xml を自動生成（120 URL を網羅）
・robots.txt 設定
・構造化データ（LocalBusiness / Dentist スキーマ）でリッチリザルト対応

4

Google Search Console での処理

旧プロパティで「アドレス変更」ツールを実行（同ドメイン継続なら省略可）。新サイトマップを送信し、インデックス申請。クロール状況を 30 日間モニタリング。

5

モニタリング期間（リリース後 30 日）

・404 エラーチェック
・リダイレクト健全性チェック
・Search Console のカバレッジレポート確認
・Google Analytics でのトラフィック比較
異常が発見されたら即座に対応します。

Risk & Mitigation

一般的にリニューアル直後はランキングが一時的に変動することがありますが、上記施策を丁寧に実施すれば通常 1〜2 ヶ月で元の水準に回復します。万一大きな変動が出た場合の追加対応もパッケージに含みます。

既存ベンダーからの引継ぎ事項

現行サイトをご担当いただいているパートナーから、以下の情報・権限を引継ぐ必要があります。スムーズな移行のため、本日以降早めに連絡を取り始めることを推奨します。

  • ドメイン管理
    sasakikyousei.com の登録業者（お名前.com / Value Domain 等）、契約者名義、AuthCode（移管時に必要）、有効期限
  • DNS / ネームサーバー
    現在の DNS 設定一式（A / CNAME / MX レコード）。特に @sasakikyousei.com のメール用 MX 設定
  • サーバー / ホスティング
    現行ホスティング業者と契約状況。新サーバー移行後の旧サイト維持要否（リダイレクト用に一定期間維持を推奨）
  • Google Analytics
    UA プロパティ ID（廃止済みでも履歴データ参照のため）、GA4 プロパティ ID、管理者権限の移譲
  • Google Search Console
    プロパティ所有権の移譲または共同管理者追加。過去のインデックス状況・検索クエリ履歴の参照
  • お問い合わせフォーム / 予約フォーム
    現行サイトのフォーム送信先（メール／外部サービス）、送信履歴のエクスポート
  • SSL 証明書
    現在の証明書発行業者と期限。Let's Encrypt 等の自動更新の有無
  • 過去のバックアップ・ソースコード
    念のため、現行サイトの完全バックアップを取得（移行後 1 年は保管推奨）
調査済みの事実関係（事前確認結果）

    現行は独自 CGI 実装の /yoyaku/ が稼働中（カレンダー→時間選択→フォーム送信の流れ）。A. 既存バックエンドの仕様を引き継いで同等機能を新規実装（メール通知先・確認メール文面・管理画面挙動などをそのまま再現） / B. 外部予約 SaaS（Apotool・ジニー予約・Reservia 等）に置換 / C. 一旦シンプルなメールフォームのみで運用開始 のいずれか。現行のメール送信先・予約管理画面の挙動を共有いただければ A の方針で運用継続できます。
  7. 採用情報の掲載要否
    スタッフ採用ページを設置する場合の募集職種・条件・応募方法
  8. SNS アカウントの有無
    Instagram / TikTok / LINE 公式 等。新サイトにリンク追加のため
  9. 治療メニューの検索軸（任意・追加可能）
    現状は現行サイトの構成を踏襲して「不正咬合の種類から探す」のみ実装しています。参考にした品川矯正歯科サイトには、これに加えて「年齢別で探す」（小児矯正／成人矯正）、「装置・方法から探す」（マウスピース／ワイヤー／裏側 等）の追加軸が用意されています。先生のご意向で同様の軸を追加することも可能ですので、ご希望があればお知らせください。
