Current Reservation Flow

現状の予約フロー

現在、患者さまの予約は 3 つの経路で受け付けられています。長年の運用で確立された流れであり、特に電話予約は今後も大切な窓口です。

01 / TEL

電話予約

045-871-2281。受付時間は平日 10〜12 時 / 14〜19 時、土日 10〜13 時 / 15〜19 時。初診・再診とも対応する中心的な窓口。

02 / WEB

ネット予約（初診のみ）

現行サイト /yoyaku/ の予約カレンダーから日時を選択。ただし初診相談専用で、枠が限られる旨の注記つき。再診には使えない。

03 / CARD

院内での次回予約

通院中の患者さまは診療後に「診察予約カード」で次回予約。変更・キャンセルの連絡手段は電話のみ。

現行ネット予約システムについて

現行の予約カレンダー（/yoyaku/）は、既存ベンダー様が独自開発（フルスクラッチ）された CGI システムです。長年医院の予約受付を支えてきた仕組みですが、リニューアルにあたり「このまま引き継ぐか、置き換えるか」の判断ポイントとなります（次ページ）。

03 / 11
Issues

リニューアルにあたっての課題

課題は 2 つの側面に分かれます。ひとつは独自システムを引き継ぐことの難しさ、もうひとつは患者さまの予約体験がいまの標準から離れつつあることです。

System ── 独自システム引継ぎの難しさ

・独自開発のため、仕様書やソースコードの引継ぎが前提になる
・改修・不具合対応のたびに個別開発が必要（費用と時間）
・セキュリティ更新やサーバー移転への追従も個別対応
・開発者以外が保守しにくく、属人化のリスクがある

Experience ── 患者さまの予約体験のギャップ

・ネット予約は初診のみ。数年間・月 1 回通院する矯正治療の再診はカバーされない
・予約の変更・キャンセルは受付時間内の電話のみ
・リマインドは行き届きにくく、うっかり忘れは治療計画の遅れに直結
・矯正の主要な患者層（お子さまの保護者・20〜40 代）は、日常連絡の中心が LINE

Key Insight

矯正歯科は「月 1 回 × 数年」の長いお付き合いになる診療科です。初診の予約だけでなく、通院中の患者さまとの継続的な接点まで含めて予約体験を設計することが、無断キャンセルの減少と治療のスムーズな進行につながります。

04 / 11
Our Proposal

ご提案の方針 ──「作る」から「使う」へ

予約システムをもう一度フルスクラッチで作り直すのではなく、広く使われている既製サービス（SaaS）を利用する方針をご提案します。開発費ゼロで最新機能が使え、保守やセキュリティ更新はサービス側が担ってくれます。電話予約は、どの構成でもこれまで通り継続します。
既製サービスの組み合わせ方にはいくつかのパターンがあるため、次の 3 つの軸で評価・整理します。

軸 1 / Operation

受付の手間

予約の受付・変更対応が自動化されるか、スタッフの手作業（電話応対・チャット返信・台帳転記）が発生するか。診療中に対応が滞らない仕組みかどうか。

軸 2 / Reach

通知の到達しやすさ

リマインドが患者さまに「確実に見てもらえる場所」に届くか。メールは埋もれやすく、専用アプリの通知は登録者にしか届きません。LINE は日常的に開くアプリのため到達性が最も高い接点です。

軸 3 / Barrier

患者さまのハードル

予約のために新しいアプリのインストールや会員登録が必要か。LINE の友だち追加だけで済むか。ハードルの高さは初診予約の離脱率に直結します。

この 3 軸が経営数字につながる理由

通知の到達しやすさは無断キャンセル率に直結します（歯科医院でリマインド導入により 8% → 2% に低下した事例あり）。矯正治療は月 1 回 × 数年の通院なのでリマインドの回数が多く、効果が累積します。受付の手間はスタッフの人件費・応対品質に、患者さまのハードルは初診予約の取りこぼしに、それぞれ跳ね返ります。

比較のまとめ ── ポチコと歯科特化型の違い

違いは「患者さま向けの予約機能だけか、院内業務（アポ帳・リコール・レセコン連携）のデジタル化まで含むか」です。歯科特化型は院内の予約台帳ごと置き換えるため機能は厚い一方、初期費用と受付オペレーションの変更を伴います。今回の目的はネット予約の置き換えと患者接点の改善であり、院内運用は現状のまま活かせるため、まずはポチコ（月 3,000 円・初期 0 円）で始め、将来アポ帳のデジタル化まで踏み込む際に Ci イージーアポ2 等へ移行する二段構えを推奨します。

Site Integration

新サイトでの予約動線

新サイト（デモ）には、PC では画面右のサイドボタン、スマートフォンでは画面下部の固定バーとして、常時表示の予約動線をすでに設けています。ここに LINE 予約を組み込みます。

  • SP下部固定バー「TEL / WEB予約 / 初診相談 / アクセス」
  • WEB予約暫定の予約フォームページ（/booking/）へ遷移

LINE 予約 組み込み後

  • PC「WEB予約」を「LINE予約」に置換、LINE 公式アカウントへ直接遷移
  • SP下部固定バーからワンタップで LINE 予約へ（アプリが直接開く）

09 / 11
Setup Steps

導入までのステップ

導入は以下のステップで進みます。医院さまの診療を止めることなく、Web サイトリニューアルの公開スケジュールと並走できます。

1

LINE 公式アカウントの開設・認証申請

医院さまの正式名称でアカウントを作成し、認証済アカウント（青バッジ。LINE 内検索に表示される）を申請します。審査は 10 日前後で、医療機関は開設届の写し等の提出を求められる場合があります（書類は医院さまにご用意いただきます）。

2

予約ツールの契約・予約枠の設定

予約ツール（ポチコ）を LINE 公式アカウントに接続し、初診相談の予約枠（曜日・時間帯・所要 40 分）を現行カレンダーと同じ条件で設定します。

3

あいさつメッセージ・リッチメニューの整備

友だち追加時のあいさつ、トーク画面下部の「予約する・アクセス・診療時間」メニューボタンを設定します。

4

新サイトへの動線組み込み

サイドボタン・下部固定バー・初診ページ等を LINE 予約導線に更新します。

5

動作確認・運用レクチャー

テスト予約で全経路を確認し、受付スタッフさま向けに管理画面の操作をご説明します。

Decisions

ご判断・ご確認いただきたい事項

本日の商談では、以下の点についてご意向をお聞かせください。

  • 予約対応をリニューアルのスコープに追加するか

    追加いただく場合、上記 3 プランからのご選択となります。

  • 実現パターンと予約サービスの選定

    推奨のパターン D（LINE 統合型：LINE 公式アカウント＋ポチコ、月 3,000 円〜）で進めてよいか。品川矯正歯科さんと同様のパターン C（並置型）や、歯科特化システム（Ci イージーアポ2 等）をご希望の場合は再検討します。

  • 対応プラン（ライト・スタンダード・フルサポート）のご選択

    迷われる場合は、開設から運用レクチャーまで一括でお任せいただけるフルサポートプランを推奨します。

  • 現行ネット予約（/yoyaku/）の停止時期

    新サイト公開と同時に LINE 予約へ切り替え、現行カレンダーは公開停止とする想定です。既存ベンダー様への連絡は引継ぎ事項に含めます。

  • LINE 公式アカウントの名義・管理者

    アカウントは医院さま名義での開設となります。管理者権限は院長先生（または受付責任者さま）に設定し、弊社は運用支援の権限で参加します。
